# oned-github-search

## 開発関連

NextJSらしい実装を考えて開発を進める

### 実装の流れ

1. 画面作成
2. api通信の関数作成
3. コンポーネント分け
4. バリデーション追加

### 設計

再利用性
読みやすさ
ServerComponent, ClientComponentの使い分け

### validation

現在のプロジェクト単位では不要。
今後、プロジェクトで必要になる場合、zodを利用する予定。

### Loading

Loadingが必要な部分は可能な限りSkeltonを入れる。

### テストコード

#### 使用パッケージ

vitest

#### 作成方法

api通信ロジックの単体テストをロジックファイルと同じ階層に作成

#### 作成対象

正常系・準異常系

※異常系に関してはエラーが発生した際に対処

### AI利用

初期段階においてAIを積極的に利用し、コードを作成する場合、アプリケーションの規模が大きくなるにつれてコードを読む工数が大きくなると思っています。
この課題ではコードソースコードの作成よりは、設計の壁打ち・テストコード作成で利用しました。

### 使用方法

- AGENTS.mdにコードレビューの方針を記入
- 英語で記入
  - aiの確認を目的とするファイルのため英語で記入
  - 確認・修正が必要な場合は英語を日本語に翻訳
